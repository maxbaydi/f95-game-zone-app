# Документация фич

Одна строка на фичу: ссылка и назначение. Шаблон документа — в глобальных правилах (`~/.claude/CLAUDE.md`).

- [Живая проверка зеркал (`check:mirrors`)](check-mirrors.md) — прогон реальных ссылок через код приложения: резолвер → передача → проверка пакета, таблица PASS/ACTION_REQUIRED/FAIL, докачка, фикстуры.
- [Шаг в браузере с автопродолжением](mirror-browser-step.md) — капча/Cloudflare показываются в окне, после прохождения загрузка стартует сама.
- [Установка из файла, скачанного в своём браузере](mirror-manual-install.md) — обход зеркал, которые не пройти во встроенном окне (Turnstile, Adscore): открыть в системном браузере, выбрать скачанный файл, установка продолжается сама.
- [Результаты проверки зеркал](mirror-verification.md) — таблица по хостам с датой последней живой проверки.
- [ADR](adr/) — архитектурные решения.
- [Supabase](supabase/) — облачная часть.
- [Handoff](handoff/) — промпты передачи работы между сессиями.
