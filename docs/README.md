# Документация фич

Одна строка на фичу: ссылка и назначение. Шаблон документа — в глобальных правилах (`~/.claude/CLAUDE.md`).

- [Аудит UX и автоматизации](ux-automation-backlog.md) — что уже само, что закрыто в 1.7.0, что осталось в очереди.
- [Фоновая автоматика](background-automation.md) — уведомления об установке, автообновление приложения, автозапуск, недельные бэкапы, пароли из темы, перепроверки после сна.
- [F95‑браузер](f95-browser-workspace.md) — компактный тулбар, бейджи в адресной строке, чип передачи, плавающие уведомления вместо полос.
- [Пробник каталога F95 (`catalog:probe`)](catalog-probe.md) — сохраняет реальные ответы эндпоинта «Latest Updates» в фикстуры; по ним пишется собственная синхронизация каталога вместо внешнего пакета Atlas.
- [Живая проверка зеркал (`check:mirrors`)](check-mirrors.md) — прогон реальных ссылок через код приложения: резолвер → передача → проверка пакета, таблица PASS/ACTION_REQUIRED/FAIL, докачка, фикстуры.
- [Шаг в браузере с автопродолжением](mirror-browser-step.md) — капча/Cloudflare показываются в окне, после прохождения загрузка стартует сама.
- [Установка из файла, скачанного в своём браузере](mirror-manual-install.md) — обход зеркал, которые не пройти во встроенном окне (Turnstile, Adscore): открыть в системном браузере, выбрать скачанный файл, установка продолжается сама.
- [Распаковка пакетов и восстановление неудачной установки](install-recovery.md) — цепочка распаковщиков (zip/7z/rar/tar без внешних утилит), коды ошибок с подсказками, пароли, пакет остаётся на диске: Retry install, Install from folder; определение движка по файлам (Unity, Unreal, RPGM, Wolf, KiriKiri…).
- [Хранилище сохранений: своё облако пользователя](save-storage.md) — OneDrive/Dropbox/Google Drive/Яндекс.Диск в один клик, WebDAV и S3, шифрование, карточка подключения для другого ПК, авто-синхронизация после установки и после игры; своего облака у приложения больше нет.
- [Экспорт и импорт сохранений через файл](save-transfer.md) — zip с манифестом на одну игру или на всю библиотеку, импорт «чужих» архивов по движку, новые места сохранений (Documents, Saved Games, Flash, GameMaker), облако как необязательная надстройка.
- [Состояние установки: установлена / файлы отсутствуют / не установлена](library-install-presence.md) — проверка папок на диске, бейджи и фильтр, «Install» вместо «Update» для игр без файлов.
- [Режимы пересканирования библиотеки](library-rescan-modes.md) — Find New Games, Refresh Installed Games, Reset Scan Cache, Rebuild Library From Scratch с резервной копией.
- [Целостность данных библиотеки](library-database-integrity.md) — апострофы без удвоения (миграция 010), асинхронный размер папок, полное удаление через `remove-game`.
- [Ремонт версий: Locate, выбор .exe, удаление версии](library-version-repair.md) — указать новую папку перенесённой игры, выбрать файл запуска, убрать лишнюю версию.
- [Массовые действия для игр без файлов](library-missing-bulk-actions.md) — Reinstall all (очередь по одной игре) и Remove all from library в фильтре «Files missing».
- [Резервные копии библиотеки](library-backups.md) — список, создание и восстановление копий базы библиотеки в настройках.
- [Игры без совпадения с каталогом](library-catalog-link.md) — автодобавление явных игр без совпадения, бейдж «Not matched», Link to catalog…, правка названий.
- [Проверка обновлений по живым темам F95](library-live-update-check.md) — версии из заголовков тем, фоновая и ручная проверка, таблица `library_live_versions`.
- [Панель деталей игры](library-details-panel.md) — всё из удалённого окна «Edit Game Details» теперь в боковой панели.
- [Панель библиотеки и меню](library-toolbar-and-menus.md) — меню пересканирования в окне, запоминание сортировки/фильтра, перепроверка без сканирования, итоги сканирования, вход в F95 из окна установки.
- [Результаты проверки зеркал](mirror-verification.md) — таблица по хостам с датой последней живой проверки.
- [ADR](adr/) — архитектурные решения.
- [Handoff](handoff/) — промпты передачи работы между сессиями.
