# F95Launcher 1.9.1

Fixes installing and updating games from F95zone after the site changed its
download links.

- F95zone replaced the old masked links in game threads with its own
  download page ("Continue to <host>"). F95Launcher found no mirrors in the
  thread, so installs and updates did not start. Mirrors are found again and
  the download page is passed automatically: pick a build and a mirror as
  before and the download starts by itself.
- The real file host of every link (Pixeldrain, MEGA, Gofile, Buzzheavier…)
  is shown again in the mirror list, including hosts the thread names only by
  their icon.
- F95 download links work for a few hours after the game page was opened.
  **Retry** and queued downloads now re-read the game page and take a fresh
  link of the same mirror instead of failing.
- If F95 asks for a check on its download page, the page opens in a window;
  finish it there and the download continues.

You still need to be logged in to F95 in the app: F95 shows download links
only to signed-in members.

Validation: lint, JSX and typecheck; full automated tests; live checks with a
signed-in account on seven popular threads (all mirrors found, hidden decoy
links skipped) and a full Pixeldrain download (181 MB zip, archive verified).
