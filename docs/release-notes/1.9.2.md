# F95Launcher 1.9.2

Faster startup, safer save recovery, and fixes across the interface.

- The interface now loads precompiled scripts instead of compiling them at every launch. Local demo measurements dropped from about 5 seconds to under 1 second; actual startup time depends on your PC and library.
- Save imports and cloud restores stop if the safety backup cannot be created. A failed backup no longer removes the previous working copy, and damaged or incomplete save archives are rejected before overwriting local saves.
- When saves have changed on both PCs, the app asks which copy to keep instead of choosing by file timestamps. Switching storage waits for active operations to finish.
- Fixed overlapping header controls, clipped toolbars and game details, narrow-window dialogs, banner proportions, and release dates. Keyboard focus stays inside dialogs and returns correctly when they close.
- Fixed stale catalog-search results, folders disappearing during setup, and setup closing after a failed settings save. Requesting encrypted storage with an empty passphrase now shows an error.
- Downloads can be retained on filesystems without hard-link support. Failed settings writes preserve the previous configuration.
- Storage setup now focuses on synced folders, WebDAV and connection cards. Manual infrastructure forms were removed. Existing Supabase connections using privileged server keys are rejected; reconnect using a supported connection card or a synced folder.
- Fixed missing UI assets in packaged builds and added packaging checks for Windows and Linux.

Validation: 649 automated tests, lint/typecheck/JSX checks, 44 browser UI scenarios, and native Windows checks of all three windows and settings-write failure recovery using isolated profiles. Live F95 authentication, real cloud accounts, and installer execution were not retested in this review.
