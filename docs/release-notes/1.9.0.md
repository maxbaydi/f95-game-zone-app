# F95Launcher 1.9.0

- Game cards smoothly reveal all tags on hover or keyboard focus. Full tags
  are also visible in game details, and clicking one filters the library.
- Search the existing library with several tags in AND or OR mode, together
  with the title/creator query and existing library views.
- Choose Games-category tags from search suggestions, or expand the complete
  tag list. The full list is collapsed by default.
- Find games on F95 carries the selected tags, AND/OR and title query into
  the website's existing search workspace.
- Enable **Keep downloads without unpacking** in Settings → Library & folders
  to save original archives. Install them later from Downloads while keeping
  the original file. Saved files remain after restarting or clearing history.

The archive option defaults to off, preserving automatic installation.

Validation: CSS build, lint, JSX and typecheck; full automated tests; Electron
tag-picker and AND/OR navigation checks; real archive download, restart and
explicit-install checks in an isolated profile. Existing user games and saves
were not used for verification.
