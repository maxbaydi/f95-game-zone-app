**F95Launcher 1.8.1 — game overviews are back**

Download: https://github.com/maxbaydi/f95-game-zone-app/releases/latest
Source: https://github.com/maxbaydi/f95-game-zone-app
Installed 1.3+ versions update themselves through the built-in updater.

- **Overview from the thread.** The game list the launcher reads from F95 has no description, so 1.8.0 left the Overview box empty. The launcher now reads the starter post whenever it opens a thread (installing or updating from the F95 browser, and the background version check of installed games) and keeps the overview in its catalog.
- **Language, platform, censorship and release date** come from the same post and are shown in the details panel again.
- A thread that was never opened shows "No overview yet" until the launcher reads it; the background check covers your favorites first (every installed game, if that option is on).
