# Целостность данных библиотеки: кавычки, размер папок, удаление

**Статус:** active
**Модули:** src/database.js, src/main/db/migrations/010_unescape_sql_quotes.js, src/main/folderSize.js, src/main.js (`remove-game`, persistF95InstalledGame, backfillMissingVersionFolderSizes)
**Тесты:** test/databaseQuoteEscaping.test.js, test/folderSize.test.js, test/migrations.test.js; `node --test test/databaseQuoteEscaping.test.js test/folderSize.test.js test/migrations.test.js`

## Назначение
Несколько давних дефектов слоя данных портили библиотеку незаметно для пользователя: апострофы в названиях и путях удваивались при записи, из-за чего пути к играм переставали существовать, а версии не находились; подсчёт размера папки замораживал окно на многогигабайтных установках; устаревший IPC удалял игру, оставляя «висячие» версии и картинки. Этот документ фиксирует исправления.

## Для пользователя
- Игры и папки с апострофами (`Lily's Garden`, `C:\Users\O'Brien\Games`) теперь запускаются, обновляются и показываются с обычным апострофом. Существующие записи исправляются автоматически при первом запуске новой версии.
- Установка большой игры больше не «подвешивает» окно на этапе подсчёта размера.
- Удаление игры из любого места интерфейса удаляет запись полностью (версии, ссылки на каталог, обложки).

Ничего включать не нужно.

## Как это работает
1. **Кавычки.** `addGame`, `updateGame`, `addVersion`, `updateVersion`, `checkRecordExist`, `updateBanners`, `updatePreviews` передают значения как параметры SQL без ручного удвоения `'`. Миграция `010_unescape_sql_quotes` один раз выполняет `REPLACE(x, '''''', '''')` в `games` (title, creator, engine), `versions` (version, game_path, exec_path), `banners.path`, `previews.path` с `UPDATE OR IGNORE`: если «раскавыченная» строка столкнётся с уже чистым дубликатом по уникальному ключу, строка остаётся как была и остаётся читаемой. Чтение `engine` по-прежнему заменяет `''` на `'` для совместимости.
2. **Размер папок.** `getFolderSizeAsync` обходит дерево через `fs.promises`, каждые 50 каталогов уступает event loop, пропускает нечитаемые подпапки, для отсутствующего пути возвращает 0, для файла — его размер. Используется при установке из темы, при импорте с `scanSize` и в фоновом дозаполнении `folder_size`.
3. **Удаление.** Канал `remove-game` теперь вызывает `deleteGameCompletely` и рассылает `game-deleted`; основной путь удаления (`remove-library-game`) не изменился.

## Контракт
- Миграция: версия 10, имя `unescape_sql_quotes`; регистрируется в `src/main/db/migrations/index.js`.
- `getFolderSizeAsync(path, { readdir?, stat? }) → Promise<number>`.
- IPC `remove-game(recordId) → { success, error? }` (раньше всегда `{ success: true }` и удалял только `games`).

## Граничные случаи и ошибки
- Название с двумя подряд апострофами, записанное новой версией, миграцией не затрагивается (она уже применена); такие названия крайне редки.
- Конфликт уникальности при раскавычивании → строка пропускается (`OR IGNORE`), в логе миграции ошибок нет.
- Папка исчезает во время подсчёта размера → отдельные файлы пропускаются, результат частичный, без исключения.
