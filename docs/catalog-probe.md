# Пробник каталога F95 (`catalog:probe`)

**Статус:** active
**Модули:** scripts/catalog-probe-electron.js, src/main/f95/session.js (`F95_AUTH_PARTITION`), src/main/f95/electronSession.js (`createElectronResolverSession`)
**Фикстуры:** test/fixtures/f95/catalog/

## Назначение
Каталог метаданных игр (названия, авторы, версии, движки, статусы, теги, обложки) приложение получало готовым пакетом с внешнего сервера проекта Atlas. Он заменяется собственной синхронизацией с F95: страница «Latest Updates» сама получает данные постранично из `sam/latest_alpha/latest_data.php`. Чтобы парсер писался по реальным ответам, а не по памяти, пробник сохраняет эти ответы в фикстуры. Нужен разработчику один раз и при изменении формата сайта.

## Для пользователя
н/п (инструмент разработчика).

## Как это работает
Скрипт запускается в Electron с сессией приложения (партиция `persist:f95-auth`), поэтому использует логин F95, сделанный в F95Launcher. Приложение при этом должно быть закрыто (проверяется single-instance lock). С паузой 1,5 с между запросами он сохраняет:

- `latest_alpha.html` и скрипты этой страницы (в них определения префиксов и тегов и точный запрос, который шлёт сама страница);
- `list-games-date-page-N.json` — список игр по дате, N страниц (по умолчанию 2 по 90 строк), плюс по одной странице сортировок `likes` и `title`, страницу за пределами конца и один поисковый запрос;
- `meta-<cmd>.json` — ответы других команд того же эндпоинта (`cat`, `prefixes`, `tags`, …), если они отвечают;
- `thread-<id>.html` — первая тема из списка (`thread-<id>.post.txt` — текст её стартового поста, по нему тестируется разбор обзора);
- `manifest.json` — URL, статус, тип содержимого, размер и SHA-256 каждого ответа.

CSRF-токены, `xf_session` и имя аккаунта в HTML вырезаются. Перед коммитом файлы всё равно стоит просмотреть.

## Контракт
```
npm run catalog:probe -- [--pages 2] [--rows 90] [--out test/fixtures/f95/catalog]
                         [--cookies cookies.txt] [--user-data <dir>]
```
Коды выхода: 0 — записано; 2 — в профиле нет логина F95 (войдите в приложении или передайте `--cookies` с Netscape-экспортом); 3 — профиль занят приложением.

## Граничные случаи и ошибки
- Ответ не JSON (например, страница входа или Cloudflare) сохраняется как `.txt`, в манифесте пометка `not JSON`.
- Команды `meta-*` могут отвечать 404 или пустым JSON: это нормально, в манифесте виден статус.
- Сетевые ошибки одного запроса не прерывают прогон.

## Проверка
1. Закрыть F95Launcher, выполнить `npm run catalog:probe`.
2. В консоли: `logged in: true`, для `list-games-date-page-1` строка `row keys=…` с полями записи.
3. `git add test/fixtures/f95/catalog && git commit` — фикстуры попадают в репозиторий, по ним пишется парсер.
